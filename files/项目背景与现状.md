# 项目背景与现状

**项目**：个人考公备考工具集，部署在 https://curly-hair-yy.github.io/yystudy/

**GitHub**：仓库 `Curly-hair-yy/yystudy`，本地已 clone 到 `~/Documents/yystudy`，已配置好 git 推送权限（通过 `gh auth login`）

**Claude Code**：已经打通，项目改动可以直接在 Code 里说需求、改完让它 `git push` 发布，不用再手动上传压缩包

## 5 个工具

- 资料分析·错题本
- 图推错题整理
- 小分互换记忆卡
- 翻译推理知识点
- 电子积木沙盒

前 4 个都已经接上 **Supabase 云同步**（Sydney 区域，项目名 yystudy，表 `app_data`），编辑内容会自动同步、任何设备/浏览器都能看到最新数据。

## 技术要点

- **资料分析·错题本**：用 `window.storage`（`storage-polyfill.js` 提供）读写云端
- **图推错题整理**：笔记数据（带图片截图，体积大）按模块分批同步，避免单次请求超过 Supabase 接口限制；用 `cloud-localstorage-sync.js` 处理其余小型本地存储项，并用 `data-exclude-prefix="tuitui-notes"` 排除大数据键，避免占满浏览器本地存储配额
- **小分互换记忆卡、翻译推理知识点**：用 `cloud-localstorage-sync.js` 通用同步所有 localStorage 键

## 已知遗留问题

图推工具"浏览"页里，部分知识点的编辑记录（除了叠加、线、对称这 3 个）还没有从旧版本迁移过来，用户表示先不处理，以后想起来再弄。

## 常见提醒

改完东西刷新看不到效果，大概率是浏览器缓存或 GitHub Pages 服务器缓存没刷新，强制刷新（Cmd+Shift+R）或者加个 `?v=数字` 的地址后缀能绕开，通常等几分钟也会自动更新。

日常代码改动优先用 Claude Code 做（能直接读写本地文件、测试、推送）。这个 Project 空间主要用于讨论方向、设计决策、排查复杂问题。
